# پوشهٔ مدل‌های اختیاری ONNX

برای استفاده از MODNet (لبهٔ دقیق‌تر مو)، فایل ONNX آن را با نام دقیق زیر اینجا بگذارید:

```
models/onnx/modnet.onnx
```

یا از داخل برنامه: «تنظیمات و مدل‌های آفلاین» ← MODNet ← «نصب از فایل».

## مدل‌های بهبود کیفیت

- `realesr-general-x4v3.onnx` (بزرگ‌نمایی ۴ برابر، ۴٫۶ مگابایت، BSD-3-Clause): همراه برنامه است.
- `gfpgan-v1.4.onnx` (بازسازی جزئیات چهره، حدود ۳۴۰ مگابایت، Apache-2.0): به‌خاطر حجم در مخزن نیست. یکی از این دو راه:
  - `node tools/fetch-optional-models.mjs` (دانلود و بررسی چکسام، بعد اینجا می‌گذارد)، یا
  - فایل را خودتان بگیرید و از داخل برنامه «تنظیمات و مدل‌های آفلاین» ← «نصب از فایل» بزنید (چکسام بررسی می‌شود).

راهنمای کامل، مجوز و مشخصات: `docs/ai-models.md`
