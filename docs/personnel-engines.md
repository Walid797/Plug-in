# پنج موتور ویرایش عکس پرسنلی (۳×۴)

این صفحه می‌گوید هر مورد از فهرست «تنظیمات و معیارهای عکس پرسنلی» در برنامه چطور پیاده شده است — و **کدام موارد پیاده نشده‌اند** و چرا. همه‌چیز در «قالب‌های چاپ سریع» (قالب‌ها ← تنظیم) قابل تنظیم است و با یک کلیک روی عکس اجرا می‌شود.

**اصل ثابت:** برنامه هرگز شکل صورت، اندازهٔ چشم‌ها، بینی، لب، خط رویش مو، ریش، سن ظاهری یا هویت را تغییر نمی‌دهد. تنها تغییر هندسی، «کادر» است (بریدن، چرخش صاف‌کردن سر و بزرگ‌نمایی یکنواخت، بدون کشیدگی). همهٔ اصلاح‌ها رنگ و روشنایی‌اند و با «واگرد» برمی‌گردند.

## مرجع کیفیت و نتیجهٔ اندازه‌گیری‌شده

قالب با یک **جفت واقعی «قبل/بعد»** تنظیم شد: یک عکس اصلی گوشی (دیوار آبی، جلیقه) و ادیت مرجع آن (پس‌زمینهٔ سفید، قاب استودیویی). عکس‌ها فقط روی ماشین توسعه‌دهنده بودند و در مخزن یا سایت **نیستند**. قالب ۳×۴ روی عکس اصلی اجرا شد و خروجی با مرجع اندازه‌گیری شد (همان قاب ۳۰×۴۰، رنگ در Lab):

| معیار | مرجع | خروجی قالب از روی عکس اصلی |
|---|---|---|
| روشنایی پوست L* | ۷۹٫۶ | ۸۰٫۲ |
| فام پوست | ۵۰٫۰° | ۴۹٫۸° |
| شدت رنگ پوست | ۳۲٫۳ | ۳۲٫۲ |
| وضوح صورت (Laplacian) | ۵۱۲ | ۶۶۱ |
| وضوح مو (Laplacian) | ۵۰۷۱ | ۴۲۶۰ |
| پس‌زمینه | سفید | ۲۵۵ |
| اندازهٔ سر / ارتفاع چشم از پایین | ≈ ۲۵٫۸ / ۲۶٫۰ میلی‌متر | قاب بر پایهٔ همین اعداد (قاعدهٔ ۳×۴ از روی مرجع اصلاح شد: سر ۲۵٫۵، چشم ۲۶) |

**اندازهٔ واقعی خروجی (۳۵۴×۴۷۲ پیکسل، ۳۰۰ DPI)** با مرجع (هم‌مقیاس‌شده) مقایسه شد؛ مرجع ۱۰۸۶×۱۴۴۸ پیکسل است و جزئیات بیشتری دارد:

| معیار (۳۵۴×۴۷۲) | مرجع | خروجی |
|---|---|---|
| پوست L* / a* / b* | ۷۹٫۶ / ۲۰٫۸ / ۲۴٫۸ | ۸۰٫۳ / ۲۰٫۶ / ۲۷٫۱ |
| عمق سایه (چشم نسبت به گونه) | ‎−۲۶٫۲ | ‎−۲۶٫۱ |
| رنگ کت | ۳۰/۳۰/۳۶ | ۳۱/۲۴/۳۶ |
| رنگ مو (میانگین) | ۹۳/۶۸/۵۸ | ۱۰۳/۷۱/۶۴ |
| وضوح مو | ۵۶۴۱ | ۶۰۲۲ |
| پیراهن | ۲۲۴/۲۲۹/۲۴۸ | ۲۰۵/۲۱۲/۲۳۲ |
| وضوح صورت | ۷۳۱ | ۱۱۶۵ (پوست واقعی با کک‌ومک؛ مرجع روتوش‌شده و صاف‌تر است) |

**تفاوت‌هایی که نمی‌توان صادقانه حذف کرد:** (۱) لباس مرجع کت مشکی است ولی عکس اصلی جلیقه؛ لباس در مرجع بازسازی شده و قالب برداری کیفیت را پایین می‌آورد، پس تغییر لباس کار جداگانهٔ بخش «لباس» است. (۲) موی مرجع گرم‌تر و پررنگ‌تر و با جزئیات بازسازی‌شده است؛ برنامه تار موی ناموجود نمی‌سازد و رنگ مو را عوض نمی‌کند. (۳) پیراهن در مرجع روشن‌تر است (۲۲۹ در برابر ۲۰۸).

**اجرای قالب روی خود مرجع** (عکس از قبل خوب) آن را **دوباره ادیت نمی‌کند**: روشنایی پوست ۷۹٫۶ → ۷۹٫۷، پیراهن ۲۲۴/۲۲۹/۲۴۸ → ۲۱۸/۲۲۲/۲۴۱، پس‌زمینه ۲۵۵، جزئیات مو حفظ شد.

### چهار سازوکار برای رسیدن به این کیفیت
۱. **قاب بر پایهٔ مرجع:** قاعدهٔ ۳×۴ سر ≈ ۲۵٫۵ و خط چشم ≈ ۲۶ میلی‌متر از پایین (قبلاً ۲۸ و ۲۳٫۵ حدسی بود).
۲. **قدرت تطبیقی:** روشن‌سازی (نوردهی، روشنایی، سایه‌ها، سفیدها) متناسب با تاریکی چهره، و وضوح و وضوح موضعی متناسب با نرمی چهره. چهرهٔ تاریک و نرم مقدار کامل می‌گیرد؛ عکس به‌اندازهٔ مرجع روشن و واضح هیچ. پس از آن نوردهیِ ملایم به‌سمت روشنایی مرجع، حداکثر ‎+۰٫۵ EV (تا پوست تیره «سفید» نشود).
۳. **وضوح موضعی (Clarity) آگاه از پوست:** مو، ابرو، ریش و لباس کامل، پوست حدود ۳۵٪؛ مو کریسپ می‌شود و پوست «خشن» نمی‌شود. (روی طیف، رنگ پوست هر عکس جداگانه اندازه‌گیری می‌شود.)
۴. **پس‌زمینهٔ سفید از قبل:** اگر پس‌زمینه از قبل سفید خالص باشد، جایگزین نمی‌شود (جداسازی فقط جزئیات ریز مو را نرم می‌کند)؛ فقط پیکسل‌های خنثی و تقریباً سفید به ۲۵۵ می‌رسند.

### کدام قالب‌ها؟
مقدارهای موتورها (قدرت تطبیقی، Clarity ۵۵، Sharpness ۲۲، پر کردن سایه ۴۵، توازن پوست ۴۰، موتور پوست و نور، شانه‌ها، پس‌زمینهٔ سفید) در **هر چهار قالب آماده و هر قالب تازه** هستند (آزمون واحد). **طبق درخواست استودیو، همهٔ قالب‌ها فقط مقدارهای مرجع را دارند:** قالب‌ها و تنظیم‌های ذخیره‌شدهٔ قبلی (تنظیم قالب‌های آماده و قالب‌های ساخت خودتان) یک‌بار موقع باز شدن برنامه پاک شدند و یک نسخهٔ پشتیبان از پاک‌شده‌ها روی همان دستگاه می‌ماند (قالب‌ها ← «دانلود پشتیبان»؛ با «وارد کردن قالب‌ها» برمی‌گردد؛ «حذف پشتیبان» آن را برای همیشه پاک می‌کند). قاعدهٔ ۴×۶ هم با همان نسبت‌های مرجع است (سر ۶۳٫۷٪، چشم ۶۵٪ از پایین). **قاب مرجع (سر ۲۵٫۵، چشم ۲۶) برای دو قالب ۳×۴ و همان نسبت‌ها برای ۴×۶** است. فقط **پاسپورت ۳٫۵×۴٫۵ عمداً قاعدهٔ ICAO** (سر ۳۴ از ۴۵ میلی‌متر) را نگه می‌دارد: سر در مرجع ≈ ۶۴٪ ارتفاع است ولی پاسپورت‌های استاندارد سر بزرگ‌تری می‌خواهند و تغییرش ممکن است عکس را برای پاسپورت نامعتبر کند. عکس‌هایی که قبلاً با قالب ساخته‌اید تغییر نمی‌کنند؛ قالب را دوباره اجرا کنید.

## ۲. رنگ پوست (موتور چهره و پوست)

رنگ پوست **از خود صورت اندازه‌گیری می‌شود** (نه از یک جدول ثابت)، پس برای هر رنگ پوستی کار می‌کند؛ ناحیه‌هایی که با آن رنگ نمی‌خوانند (لب، چشم، ابرو، مو، ریش) از پردازش بیرون می‌مانند. آزمون با پوست روشن، متوسط و تیره.

| مورد | وضعیت | توضیح |
|---|---|---|
| رنگ طبیعی و گرم | ✅ | دمای رنگ +۲؛ رنگ پوست «یکسان‌سازی» نمی‌شود |
| اصلاح قرمزی بیش‌ازحد | ✅ | فقط بخشی از قرمزی که بالاتر از حد طبیعی (نسبت ۱٫۵ قرمز به زرد) است، تا سقف ۷ سطح، به‌صورت انتقال نرم؛ پوست طبیعی دست نمی‌خورد (آزمون) |
| توازن رنگ پوست | ✅ | لکه‌های رنگی بزرگ یکنواخت می‌شوند، جزئیات ریز دست نمی‌خورد |
| جلوگیری از سفیدشدن | ✅ | روشن‌کردن فقط سایه‌هاست و سقف دارد؛ آزمون: میانگین روشنایی پوست کمتر از ۱۰ سطح بالا می‌رود |
| بافت پوست | ✅ | هیچ تاری یا صاف‌کردنی اعمال نمی‌شود؛ آزمون انرژی بافت (±۲۰٪) |
| رنگ لب و چشم | ✅ | بیرون از ناحیهٔ پوست؛ آزمون: دقیقاً بدون تغییر |

## ۴. تنظیم رنگ (Color Grading)

مقادیر پیش‌فرض همهٔ قالب‌ها همان جدول پیشنهادی شماست. **این‌ها مقادیر پیشنهادی‌اند، نه مقادیر ثبت‌شده از یک پردازش** و باید روی عکس خودتان بررسی شوند.

| تنظیم | مقدار | توضیح |
|---|---|---|
| Exposure | +۰٫۱۵ EV | روی لغزنده ۷٫۵ (لغزنده ±۱۰۰ = ±۲ EV) |
| Brightness | +۸ | |
| Contrast | +۸ | جدول پیشنهادی ۵ بود؛ با جفت قبل/بعد برای عمق مو و کت اصلاح شد |
| Saturation | +۳ | |
| Temperature | +۲ | |
| Tint | ۰ | |
| Highlights | −۱۰ | |
| Shadows | +۱۲ | |
| Whites | +۸ | **تازه اضافه شد** (در ویرایش عکس هم هست) |
| Blacks | −۸ | **تازه اضافه شد**؛ جدول پیشنهادی ‎−۳ بود و با جفت قبل/بعد اصلاح شد |
| روشن‌کردن میانه و روشن‌ها (Lift) | خودکار | **تازه**؛ روشن‌سازی چهره میانه و روشن‌ها (پوست، پیراهن) را بالا می‌برد ولی تیره‌ها (مو، کت، ابرو) را کم‌تر؛ برخلاف نوردهیِ کلی که مو را خاکستری می‌کند |
| Sharpness | ۲۲ | افزایش جزئی (تطبیقی با نرمی چهره) |
| وضوح موضعی (Clarity) | ۵۵ | **تازه**؛ مو، ابرو، ریش کریسپ؛ پوست کم (تطبیقی با نرمی چهره) |
| کاهش نویز رنگی | ۳۰ | **تازه اضافه شد** |

پس‌زمینهٔ سفید **بعد از** این تنظیم‌ها جایگزین می‌شود، پس هرگز خاکستری نمی‌شود. اجرای قالب، تنظیمات نور و رنگ قبلی آن عکس را با این مقادیر جایگزین می‌کند (با واگرد برمی‌گردد؛ با خاموش‌کردن «موتور تنظیم رنگ» در قالب، دست نمی‌خورد).

## ۶. چهره

همهٔ ۹ مورد (شکل صورت، اندازهٔ چشم، بینی، لب، حالت، خط رویش مو، ریش و سبیل، سن، هویت) **با طراحی تضمین می‌شوند**: هیچ مرحله‌ای هندسهٔ صورت را تغییر نمی‌دهد. موتورها فقط رنگ و روشنایی را روی پوست تغییر می‌دهند؛ ریش و مو در ناحیهٔ پردازش نیستند (آزمون: ریش، لب، چشم و ابرو دقیقاً بدون تغییر). ماتریس کادر مقیاس یکنواخت دارد (آزمون واحد کادر).
