## معماری انتخاب‌شده

- کد ماژولار ES (Preact برای رابط) که با esbuild به یک **اسکریپت کلاسیک** ساخته می‌شود تا از `file://` هم باز شود.
- هستهٔ خالص و آزمون‌پذیر برای چیدمان، PDF، DPI، ZIP و هندسه.
- IndexedDB + OPFS، Service Worker برای PWA، راه‌اندازهای بی‌نیاز از نصب (Node، Python، PowerShell).
- هوش مصنوعی محلی: MediaPipe Tasks (همراه برنامه) و ONNX Runtime Web با WebGPU/WASM برای مدل اختیاری.
