# هوشمند فوتو استودیو

استودیوی **آفلاین** برای عکس‌های تذکره، پاسپورت، مکتب، کارمندی و عکس شخصی: وارد کردن عکس، کادربندی و اصلاح نور، استانداردسازی چهره با هوش مصنوعی محلی، حذف و تغییر پس‌زمینه، و چیدمان و **چاپ با اندازهٔ دقیق فیزیکی** روی کاغذ عکس.

> **آفلاین — عکس‌های شما روی همین دستگاه باقی می‌ماند.**
> برنامه هیچ عکسی، داده‌ای یا آماری به انترنت نمی‌فرستد. هیچ سرویس ابری، ردیاب یا فراخوانی پنهان شبکه ندارد.

## نصب و راه‌اندازی آفلاین

### دریافت

کل پوشهٔ برنامه را (مثلاً فایل ZIP مخزن) یک بار دریافت و روی کمپیوتر باز کنید. **هیچ نصب دیگری لازم نیست**؛ برنامه، قلم فارسی، موتورهای هوش مصنوعی و مدل‌ها همه در همین پوشه هستند (حدود ۷۰ مگابایت).

### نسخهٔ ویندوز (exe)

برای نصب‌کنندهٔ ویندوز با به‌روزرسانی خودکار و کار آفلاین: [docs/desktop-exe.md](docs/desktop-exe.md) (پوشهٔ `desktop/`، ساخت خودکار با GitHub Actions).

### روش ۱ — راه‌انداز محلی (پیشنهادی، همهٔ امکانات)

راه‌انداز یک سرور کوچک **فقط روی همین کمپیوتر** (نشانی `127.0.0.1`) روشن می‌کند و مرورگر را باز می‌کند. این سرور از بیرون یا شبکه در دسترس نیست و فقط پوشه‌های لازم برنامه را نشان می‌دهد.

| سیستم | کار |
|---|---|
| ویندوز | روی `start-windows.bat` دوبار کلیک کنید. اگر Node.js یا Python نصب باشد از آن استفاده می‌شود؛ وگرنه از PowerShell خود ویندوز. |
| مک | روی `start-mac.command` دوبار کلیک کنید (بار اول: راست‌کلیک ← Open). به Node.js یا Python 3 نیاز دارد. |
| لینوکس | در پایانه: `./start-linux.sh` (Node.js یا Python 3). |
| دستی | `node server/serve.mjs` یا `python3 server/serve.py` و سپس باز کردن `http://127.0.0.1:8787/` |

اگر درگاه ۸۷۸۷ مشغول باشد، درگاه بعدی خودکار انتخاب و در پنجره نوشته می‌شود. برای بستن، پنجرهٔ راه‌انداز را ببندید.

### روش ۲ — نصب به‌عنوان برنامه (PWA)

پس از باز کردن با راه‌انداز، در Chrome یا Edge از نوار نشانی گزینهٔ «نصب برنامه / Install» را بزنید. پس از نصب، برنامه **حتی وقتی راه‌انداز خاموش است** باز می‌شود؛ ویرایش، چاپ و مدل‌هایی که یک بار استفاده شده‌اند آفلاین کار می‌کنند.

> Service Worker (لازمهٔ PWA) فقط روی `localhost`/`127.0.0.1` یا HTTPS کار می‌کند و از صفحه‌ای که مستقیم از فایل (`file://`) باز شده کار **نمی‌کند**.

### روش ۳ — باز کردن مستقیم `index.html`

روی `index.html` دوبار کلیک کنید. ویرایش، کادربندی، ذخیره، چاپ و PDF کار می‌کند، اما مرورگر در حالت `file://` بارگذاری مدل‌های هوش مصنوعی را مسدود می‌کند؛ بنابراین تشخیص چهره و حذف پس‌زمینه غیرفعال است و دلیل آن در برنامه نوشته می‌شود. برای این امکانات از روش ۱ استفاده کنید.

### روش ۴ — نسخهٔ آنلاین (Render)

نشانی: **https://hoshmand-photo-studio.onrender.com**

- همان برنامه است که به‌صورت فایل‌های ایستا از CDN رندر بارگذاری می‌شود. **هیچ سرور یا پایگاه‌داده‌ای پشت آن نیست**؛ عکس‌ها همچنان فقط در مرورگر شما پردازش و ذخیره می‌شوند و هرگز آپلود نمی‌شوند.
- فقط اولین باز کردن به انترنت نیاز دارد. پس از آن (به‌ویژه اگر «نصب برنامه / Install» را بزنید) برنامه و مدل‌هایی که یک بار استفاده شده‌اند بدون انترنت هم کار می‌کنند.
- در اولین بازدید، WebAssembly تک‌رشته‌ای است؛ از بازدید دوم که Service Worker فعال شد، چندرشته‌ای می‌شود (فقط برای مدل اختیاری ONNX مهم است).
- اتصال به «موتور محلی» تغییر لباس (127.0.0.1) از نسخهٔ آنلاین ممکن است توسط مرورگر مسدود شود یا اجازهٔ «دسترسی به شبکهٔ محلی» بخواهد؛ برای آن بخش از راه‌انداز محلی استفاده کنید.
- با هر push روی شاخهٔ `claude/hoshmand-photo-studio-5yvqy9` نسخهٔ آنلاین خودکار به‌روز می‌شود. ساخت با `node tools/publish-static.mjs` فقط فایل‌های لازم (app، vendor، models، icons، docs) را منتشر می‌کند؛ کد منبع، آزمون‌ها و تنظیمات منتشر نمی‌شوند.

### مرورگرهای پشتیبانی‌شده

Chrome و Edge جدید (پیشنهادی)، Firefox جدید، Chrome اندروید. Safari در iOS/iPadOS با محدودیت (بخش «محدودیت‌ها» در [docs/test-report.md](docs/test-report.md)).

### موبایل

- **اندروید:** پوشهٔ برنامه را روی یک کمپیوتر با راه‌انداز اجرا کنید یا از یک برنامهٔ سرور محلی اندروید استفاده کنید؛ باز کردن مستقیم فایل HTML در Chrome اندروید معمولاً ممکن نیست. ساده‌ترین راه: برنامه را روی کمپیوتر اجرا کنید و عکس‌ها را از موبایل منتقل کنید.
- **iPhone/iPad:** Safari اجازهٔ اجرای سرور محلی نمی‌دهد. برنامه برای کار روی کمپیوتر طراحی شده و رابط کاربری آن روی صفحه‌های کوچک هم کار می‌کند.

## مراحل کار

**وارد کردن ← ویرایش ← استانداردسازی ← بازبینی ← چیدمان چاپ ← خروجی**

**راه سریع:** در «صفحه اصلی» از «چاپ سریع با یک کلیک» قالب را بزنید (مثلاً «۳×۴ — تذکره، مکتب، کارمندی» = ۴ عکس برای هر نفر روی ۱۰×۱۵؛ برگه عمودی است و عکس‌ها ۹۰ درجه چرخیده ردیف‌به‌ردیف از بالا-چپ چیده می‌شوند (۲ ستون × ۴ ردیف = ظرفیت ۸ عکس)؛ فقط وقتی دقیقاً ۹ عکس روی یک برگه باشد، حاشیه و فاصله کم می‌شود و ۹ عکس ایستاده ۳×۳ جا می‌گیرند؛ بقیهٔ کاغذ سالم می‌ماند)، عکس را انتخاب کنید و در پنجرهٔ «آماده برای چاپ» دکمهٔ «چاپ» را بزنید. یک بار تنظیمات چاپگر را طبق [بخش ۲٫۵ راهنمای چاپ](docs/print-calibration.md) بگذارید.

**راه کامل:**

1. در «صفحه اصلی» کاربرد را انتخاب کنید (مثلاً «تذکره / کارت هویت» = ۳×۴) و عکس‌ها را وارد کنید.
2. در «ویرایش عکس» کادر را تنظیم کنید؛ عکس اصلی هرگز تغییر نمی‌کند و همهٔ تنظیمات قابل برگشت است (Ctrl+Z).
3. در «اصلاح هوشمند» دکمهٔ «تحلیل چهره» را بزنید، پیشنهاد را بررسی و «پذیرش» کنید.
4. در صورت نیاز در «پس‌زمینه» رنگ پس‌زمینه را عوض کنید.
5. در «استودیوی چاپ» کاغذ و تعداد را انتخاب کنید؛ پیش‌نمایش دقیقاً همان هندسهٔ چاپ است.
6. «چاپ» یا «PDF با اندازهٔ دقیق» را بزنید و فهرست بررسی پیش از چاپ را دنبال کنید.

## چاپ دقیق — نکات مهم

- اندازه‌ها همیشه به **ملی‌متر** حساب می‌شوند. برنامه هرگز عکس را کوچک، بزرگ یا کشیده نمی‌کند؛ اگر جا نشود، دلیلش را با عدد می‌گوید یا برگهٔ بعدی می‌سازد.
- مثال کاغذ ۱۰×۱۵ با عکس ۳×۴: با حاشیهٔ ۵ و فاصلهٔ ۲ ملی‌متر، حالت افقی ۸ عکس (۴×۲) و حالت عمودی ۶ عکس (با چرخاندن ۹۰ درجهٔ عکس‌ها ۸) جا می‌شود؛ **پیش‌فرض همهٔ قالب‌ها: ورق عمودی، همهٔ عکس‌ها ۹۰ درجه (۸ عکس) و ردیف‌به‌ردیف؛ و حالت ۹ عکس: وقتی دقیقاً ۹ عکس روی یک برگه باشد، حاشیه ۳٫۷ و فاصله ۲ ملی‌متر و ۳×۳ ایستاده** (هنوز از لبهٔ غیرقابل‌چاپ ۳ ملی‌متری چاپگر فاصله دارد). هر دو در «ویرایش قالب» قابل تغییرند. برنامه هر دو جهت را حساب و بهترین را پیشنهاد می‌کند — عدد ۸ از پیش تعیین نشده است.
- در پنجرهٔ چاپ: **مقیاس ۱۰۰٪ / Actual size**، خاموش کردن **Fit to page**، حاشیه **None**، اندازهٔ کاغذ درست. مرورگر کاغذِ پیش‌فرض چاپگر را به کار می‌برد و وب‌سایت نمی‌تواند تنظیمات درایور را عوض کند؛ پیش‌فرض چاپگر را یک بار روی ۴×۶، نوع کاغذ Glossy و کیفیت High بگذارید.
- در درایور، **نوع کاغذ هرگز «Plain paper» برای کاغذ عکس** نباشد (عکس تیره و خیس می‌شود). «روشن‌سازی برای چاپ» (پیش‌فرض: متوسط) تیرگی معمول چاپ جوهرافشان را جبران می‌کند.
- یک بار **برگهٔ کالیبراسیون** را چاپ و با خط‌کش اندازه بگیرید. تا زمانی که با خط‌کش بررسی نکرده‌اید، دقت چاپ را تأییدشده فرض نکنید.
- پیکسل = سانتی‌متر ÷ ۲٫۵۴ × DPI. مثلاً ۳ سانتی‌متر در ۳۰۰ DPI = ۳۵۴ پیکسل. مقدار DPI در فایل ثبت می‌شود، ولی جزئیات واقعی به وضوح عکس اصلی بستگی دارد؛ برنامه اگر عکس کم‌کیفیت باشد هشدار می‌دهد.

راهنمای کامل: [docs/print-calibration.md](docs/print-calibration.md)

پنج موتور ویرایش عکس پرسنلی (پس‌زمینه، چهره و پوست، نور، تنظیم رنگ، کادر و چاپ) و اینکه هر مورد چطور پیاده شده یا نشده: [docs/personnel-engines.md](docs/personnel-engines.md)

## حریم خصوصی و داده‌ها

- همهٔ عکس‌ها، پروژه‌ها و تنظیمات فقط در حافظهٔ همین مرورگر (IndexedDB و در صورت امکان OPFS) ذخیره می‌شوند.
- هنگام اولین ورود عکس، برنامه می‌پرسد که آیا عکس‌های اصلی ذخیره شوند یا فقط در همان جلسه بمانند.
- نقاط چهره فقط در حافظهٔ موقت برای کادربندی استفاده می‌شوند؛ هیچ «اثر انگشت چهره» (embedding) ساخته یا ذخیره نمی‌شود و هیچ عکسی برای آموزش مدل استفاده نمی‌شود.
- پاک کردن: «پروژه‌ها» ← حذف پروژه، یا «تنظیمات» ← «پاک کردن همهٔ پروژه‌ها» / «پاک کردن کامل داده‌های محلی» (با تأیید).
- سیاست امنیت محتوا (CSP) اجرای اسکریپت از هر جای دیگر را مسدود می‌کند؛ تنها اتصال مجاز بیرون از برنامه، اتصال اختیاری خودتان به موتور محلی روی `127.0.0.1` است.

```
models/                                   مدل‌های همراه (MediaPipe) و محل مدل‌های اختیاری (onnx/)

docs/                                     مستندات فارسی
```

دستورها (Node.js ۲۰ یا جدیدتر):

```
npm install          # فقط برای توسعه
npm run build        # ساخت app/ و vendor/ و sw.js
npm test             # آزمون‌های واحد (چیدمان، صفحه‌بندی، هندسهٔ PDF، DPI، ZIP، …)
npm run test:e2e     # آزمون‌های سرتاسری در Chromium (نیازمند Playwright)
npm start            # سرور محلی
```

کاربر نهایی به هیچ‌کدام از این دستورها نیاز ندارد؛ پوشهٔ `app/` و `vendor/` ساخته‌شده در مخزن موجود است.
